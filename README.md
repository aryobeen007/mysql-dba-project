# MySQL DBA Project

**Author:** Naseer Aryobee  
**Portfolio:** [nasaryobee.com](https://nasaryobee.com)  
**GitHub:** [github.com/aryobeen007/mysql-dba-project](https://github.com/aryobeen007/mysql-dba-project)
